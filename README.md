# PizDa Строй

Сайт строительной компании ООО «PizDa» — строительство загородных домов и ремонт квартир в Санкт-Петербурге и Ленинградской области.

**Стек:** Next.js (App Router) + TypeScript + Tailwind CSS 4

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Перед продакшеном (обязательно)

1. **Реквизиты** — откройте `src/lib/company.ts` и замените ИНН, ОГРН, адрес, телефон, email на реальные.
2. **Хранение заявок** — сейчас заявки пишутся в `data/leads.json` (демо) + логируются. Для продакшена используйте PostgreSQL/MySQL в РФ или российскую CRM + Telegram/email.
3. **Капча** — добавлена простая математическая проверка. При желании замените на Яндекс SmartCaptcha.
4. **Cookie-баннер** — реализован.
5. **Юридические документы** — Политика и Согласие подтягивают данные из `company.ts`. Согласуйте с юристом.
6. **Роскомнадзор** — при необходимости подайте уведомление об обработке ПДн.
7. **Хостинг** — инфраструктура в РФ или БД с ПДн в РФ.
